- Swiss Modernism meets Industrial brutalism. High contrast, grid-aligned, function-forward.

## Visual Language
- Core visual signature: Sharp geometric color blocking with bright red accents (#D82B2B) against stark white and deep navy (#2A3B4C).
- Material & depth: Flat design, zero shadows. Depth is created strictly through color contrast (white vs navy vs red).
- Containers & buttons: Sharp corners (0px border radius). Buttons are solid colored rectangles. Heavy use of full-bleed image backgrounds with solid color overlays.
- Layout rhythm: Checkerboard grid layouts mixing heavy image blocks with stark solid color blocks.

## Animation
- Entrance: Snappy, fast fade-ins.
- Interaction: Sharp color swaps on hover, no soft gradients.
- Scroll / transition: Instant rigid transitions.

## Forbidden
- No rounded corners (border-radius: 0 everywhere).
- No drop shadows.
- No gradients.

## Additional Notes
- All user-visible copy follows the user's language preference (typically English)
